# Bundle ID

Bundle ID is a macOS utility that allows you to quickly identify the Bundle Identifier (unique identifier) of any app installed on your Mac. This information is especially useful for developers, system administrators, and advanced users.

Bundle ID est un utilitaire macOS qui permet d'identifier rapidement le Bundle Identifier (identifiant unique) de n'importe quelle application installée sur votre Mac. Cette information est particulièrement utile pour les développeurs, administrateurs système et utilisateurs avancés.


- ⚠️ **Note: this application is not signed by Apple.**  
  You will need to launch it via **Right click → Open** and confirm manually in **Security Preferences**.
